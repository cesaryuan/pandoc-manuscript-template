# Bundled MiTeX Typst scope

These files provide the complete Typst runtime scope expected by the Rust
`mitex` 0.2.7 converter. The redundant `mitex.wasm` converter is intentionally
not bundled because `latex2wmf` performs conversion through the Rust crate.
